## Implemented
- [x] Two time-lapse modes: Simulation Mode (0x to 10x, the engine cap) and Clock Only Mode (up to 10000x, sky only).
- [x] Time dilation: speeds up everything including NPCs, traffic, and weather transitions.
- [x] HUD toggle: hide/show the game HUD for clean recording.
- [x] Optional: disable air traffic (flying AVs) for cleaner skyline shots.
- [x] Optional: disable crowds and street traffic for empty-city aesthetic.
- [x] Optional: Traffic Frenzy mode — speeds up ambient traffic to match timelapse rate.
- [x] Keybind-driven controls via Cyber Engine Tweaks overlay.
- [x] Settings saved to settings.json between launches.
- [x] Optional: mute the radio, the music or all sound effects for the length of a run.
- [x] Optional: lock player movement, weapons and camera during a run.
- [x] Window Utils window with Settings and Debug tabs.
